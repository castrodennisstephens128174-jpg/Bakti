The problem

Remittances reach wallets.
They don't reach habits.

SEA diaspora sends >$100B home each year. Much of it from children supporting elderly parents.

  • Ad-hoc: depends on sender remembering.
  • Apps charge opaque fees; no clean audit.
  • Recipients are often elderly. Can't use a wallet app.
  • A missed month = skipped medicine or groceries.

Current vs target

Phase 1 shipped. Phase 2 is one anchor away.

Phase 1 — shipped

  • Soroban BaktiEscrow deployed on Stellar mainnet.
  • Non-custodial signing, every payment in the sender's own wallet.
  • Signed-challenge auth (not SEP-10), SEP-23 muxed attribution, SEP-7 pay links.
  • SEP-24 cash_pickup off-ramp built to spec, run against a simulated anchor.
  • End-to-end payout — sign → verify → off-ramp → pickup — proven on testnet.

Phase 2 / 3 — target

  • Production anchor: MoneyGram Access or Coins.ph — going live is a config swap, not a rewrite.
  • Real 30-day payout cadence.
  • Pilot corridor live on mainnet with a signed anchor.
  • Multi-corridor, licensed rails.
